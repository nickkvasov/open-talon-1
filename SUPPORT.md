# Support

Use the right GitHub surface for the work:

- bug reports: open a Bug report issue with reproduction steps
- feature proposals: open a Feature request issue or start an Architecture discussion for larger design changes
- implementation tasks: open an Engineering task issue when scope is already clear
- questions: use GitHub Discussions when enabled
- vulnerabilities: follow [SECURITY.md](./SECURITY.md), not public issues

For local development problems, include the command you ran, relevant `.run/` log excerpts, service health, and whether the stack was started with `./open-talon start`. Do not include secrets, bearer tokens, raw prompt bodies, tool arguments, message bodies, or private payloads.
