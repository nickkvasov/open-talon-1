# Business Case Log Artifacts

This directory stores persistent communication-log artifacts generated by the business-case test suite when persistence is explicitly enabled.

The runtime layout is:

```text
logs/
  <scenario>/
    <test_name>/
      latest.json
      runs/
        <timestamp>_pid<pid>/
          manifest.json
          <workspace_id>.jsonl
```

Notes:

- `<scenario>` comes from the test module name without the `test_` prefix.
- `<test_name>` comes from the individual pytest test name.
- Each run gets its own timestamped directory so collaboration traces are preserved across repeated runs.
- `latest.json` points to the most recent run directory for fast navigation.
- The JSONL files are the workspace communication logs emitted during the scenario.
- By default, business-case tests write logs to pytest temporary storage. Set `OPEN_TALON_PERSIST_BUSINESS_CASE_LOGS=1` to write persistent logs here.

These generated artifacts are intentionally ignored by git.
