# Code of Conduct

Open Talon collaboration should stay direct, evidence-based, and respectful.

Expected behavior:

- focus criticism on code, docs, architecture, tests, and operational behavior
- keep security-sensitive details out of public issues, pull requests, and discussions
- assume project maintainers may ask for narrower scope, clearer reproduction steps, or stronger tests before review
- respect the repository licensing and contribution policy before submitting work

Unacceptable behavior:

- harassment, threats, discriminatory language, or personal attacks
- publishing secrets, private data, credentials, raw sensitive payloads, or vulnerability details in public project spaces
- knowingly submitting code, data, generated output, or fixtures without compatible rights

Report conduct concerns through the same private maintainer channel used for security reports in [SECURITY.md](./SECURITY.md). Maintainers may edit, hide, or remove content and restrict participation when needed to protect contributors, users, or the project.
